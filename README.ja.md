『水滸伝』の人物関係を可視化するツールです。**広く楽しみ、読み味わう** ために作りました。

`index.html` を開くだけで使えます —— 完全静的・依存ゼロ・オフライン動作。ダブルクリックで起動し、環境構築は不要です。

### 1. 画面：3 ペイン構成

| ペイン | 内容 |
| --- | --- |
| **左 1/6** | 全登場人物の名簿。**天罡三十六星 → 地煞七十二星 → 宋朝の役人 → 庶民（市井の者）** の 4 グループに分類。名前・渾名で検索可能 |
| **中（可変）** | 力学モデルによる関係図：**ノード＝人物、エッジ＝関係**。ホイールで拡大縮小、ドラッグで移動、ノードをドラッグ、ダブルクリックで中央寄せ |
| **右 1/3** | 人物やエッジを選択すると、その関係の **回目・解説・原文の抜粋** を表示 |

**3 ペインすべてサイズ変更可能**：各ペインの間には仕切りバーがあり（ホバーで発光）、左右にドラッグして幅を調整できます。**仕切りバーをダブルクリック** すると既定の比率に戻ります。中央ペインは最小 240px を確保するため、図が潰れることはありません。幅は割合（％）で保持され、ウィンドウを拡大縮小しても比率は保たれます。

**天罡と地煞**：百八人の好漢は席次によって **天罡三十六星** と **地煞七十二星** に分かれます。左の名簿もこの 2 グループに分けて表示し、図では **天罡は金色＋金の外環**、地煞は赭（あか）色の塗りつぶしで描きます。左上には関係の凡例に加えて星位の凡例もあり、見比べられます。人物にホバーすると、ツールチップに「天罡」または「地煞」と表示されます。

**表示直後から安定**：最初のフレームを描画する前に、力学シミュレーションを裏で収束させて静止させます。そのためページを開いた瞬間から図は **すでに整った状態** で現れ、初期の暴れや常時の微振動はありません。ドラッグや絞り込みなど、能動的な操作をしたときだけわずかに揺れ戻します。

右ペインの「原文抜粋」は混同を避けるため、意図的に **2 つに分割** しています：

```
┌─────────────────────────────────────────┐
│ 回目 │ 第十回 朱貴水亭に号箭を施し 林冲雪夜梁山に上る │  ← その一：出典
├─────────────────────────────────────────┤
│  原来这人是京师殿帅府太尉高俅……          │  ← その二：原文
└─────────────────────────────────────────┘
```

### 2. 二つの設計上の要点

#### ノードの大きさ ＝ 登場回数（意図的に圧縮）

半径は **対数圧縮** で算出します：

```js
norm = log(1 + 登場回数) / log(1 + 全書の最大登場回数)
半径 = 5.5 + 5.0 * norm        // 実際の範囲はおよそ 5.9 ～ 10.5 px
```

そのため宋江（4019 回）でも、数回しか登場しない脇役と比べて半径は 2 倍未満にとどまり、
**識別できる階層は保ちつつ、主役が突出しすぎない** ようになっています。

> 計数方針：全テキストから「姓名＋渾名＋別称」を照合します。潘金蓮や閻婆惜のように、
> 原作で「那婦人」「婆惜」などと総称される人物には、回を限定して代称を補っています（`build/scoped.py` 参照）。

#### 有向の関係：行為者 → 受け手

エッジには **矢印** があり、「誰が行い、誰に及んだか」を示します。全 7 種類、それぞれに色を割り当てています：

| 種類 | 意味 | 例 |
| --- | --- | --- |
| **恩** | 恩を施す／受ける | 柴進 → 林冲（匿って銀を贈る） |
| **義** | 義気・義兄弟・生死を託す | 魯智深 → 林冲（野猪林で救う） |
| **愛** | 恋慕・婚姻・密通 | 西門慶 → 潘金蓮 |
| **孝** | 孝行・人倫・養育 | 武松 → 武大郎（兄を父のように敬う） |
| **仇** | 仇敵・怨恨・確執 | 高俅 → 林冲（白虎堂の陥穽） |
| **殺** | 殺害・命を奪う・血の負債 | 李逵 → 李鬼 |
| **騙** | 欺瞞・計略・誘い込み | 呉用 → 盧俊義（智略で玉麒麟を賺す） |

左上の凡例で **種類ごとに表示・非表示を切り替え** られます。同じ二人の間に双方向の関係がある場合、エッジは自動的に上下の弓なりに分かれ、矢印が往復しても重なりません。

### 3. データ規模

| 項目 | 数 |
| --- | --- |
| 人物ノード | **183**（好漢 108 + 宋朝の役人・官差 31 + 庶民 44） |
| 関係エッジ | **215** 本、7 種類すべて |
| 原文抜粋 | **215** 件、いずれも回目付き |
| コーパス | 全 121 篇（楔子 + 120 回）、約 88.5 万字 —— **リポジトリには含まれません（第 5 節参照）** |

データファイルは非常に小さく（合計約 113 KB）、初回表示はほぼ待ち時間なしです。

### 4. ディレクトリ構成

**最小実行セット（7 ファイル、約 160 KB）** —— クローン後はこれだけで動作し、`index.html` をダブルクリックすれば使えます：

```
# ── 実行に必須 ────────────────────────
index.html            ページの骨組み（3 ペイン）
css/style.css         スタイル（宣紙と墨、中国風）
js/graph.js           力学エンジン：自作の物理シミュレーション + Canvas 描画 + 操作（依存ゼロ）
js/app.js             アプリ層：名簿・凡例・詳細の連動
data/characters.js    人物データ（自動生成）
data/relations.js     関係データ + 抜粋（自動生成）
data/chapters.js      回目索引（自動生成）

# ── リポジトリに同梱 ──────────────
README.md             ドキュメント（中文）
README.en.md          ドキュメント（English）
README.ja.md          ドキュメント（日本語）
LICENSE               MIT ライセンス
.gitignore            除外設定（セッション記録・コーパス・キャッシュ）

# ── 任意：データ生成パイプライン（Python）──
build/                データ生成パイプライン（Python、任意）
  roster.py           名簿の原データ（108 の席次・星号・渾名 + 役人 + 庶民）
  relations.py        215 件の関係の原データ（行為者・受け手・種類・回・解説）
  scoped.py           回を限定した代称ルール
  count.py            登場回数の集計 → stats.json
  chapters.py         回目索引の抽出 → chapters.json
  validate.py         検証：人名の解決、両者が実際にその回に共起しているか
  emit.py             抜粋の抽出 → data/*.js を生成
  checkjs.py          データ整合性 + JS 括弧対応のチェック

corpus/               『水滸伝』コーパスと取得・抽出スクリプト
  download.py         公開サイトから全文を取得 → corpus/raw/
  extract.py          整形して corpus/txt/ へ
  txt/                本文 121 篇（容量が大きいため .gitignore で除外）
```

したがって **最小アップロードは 7 の実行ファイル + 3 のドキュメント + `LICENSE` + `.gitignore` の計 12 ファイル**。`build/` と `corpus/` は任意です。

### 5. データの再現・拡張

リポジトリに **原作本文は含まれません**（`corpus/txt/` は `.gitignore` に登録済み）。パイプラインを再実行する場合は、まずコーパスを取得してください：

```bash
python corpus/download.py  # 0. 全文を取得 → corpus/raw/
python corpus/extract.py   #    整形 → corpus/txt/
python build/count.py      # 1. 登場回数を集計
python build/chapters.py   # 2. 回目を抽出
python build/validate.py   # 3. 関係と回を検証（"issues: 0" が期待値）
python build/emit.py       # 4. 抜粋を抽出し data/*.js を生成
python build/checkjs.py    # 5. 健全性チェック（"errors=0" が期待値）
```

**人物を追加**：`build/roster.py` に 1 行追加します。
**関係を追加**：`build/relations.py` に `(行為者, 受け手, 種類, 回, 解説)` を 1 件追加します。回はコーパスの番号です（`0`＝楔子、`1`＝第一回 … `120`＝第百二十回）。
そのうえで上記のスクリプトを実行すれば、抜粋は **自動的にその回から特定** されます —— 両者が同時に現れる段落を探し、解説の内容語で重み付けして選びます。

### 6. 抜粋はどのように作られるか

手作業の書き写しではなく、プログラムが原作から「見つけ出し」ます：

1. 対象の回を文に分割する。
2. **行為者と受け手が同時に現れる** 最小の文の窓を見つける。
3. 関係の種類のキーワード（殺→「殺／死／毒／血」、騙→「騙／賺／瞞／誘」…）と解説の内容語で重み付けして採点する。
4. OCR ノイズを含む窓を除外し、最良のものを採用する。

したがってどの抜粋も **原作そのままの本文** です。ただし、その場面で最も有名な一句とは限りません。

### 7. 補足と制約

- **回目の番号** は使用した電子テキストに準じます（その楔子「張天師 瘟疫を祈禳し 洪太尉 妖魔を誤って放つ」が独立しているため、本文の回数が一部の通行本と 1 回ずれます）。抜粋の本文と示した回目は完全に対応しており、回目名で原文を直接検索できます。
- **関係の項目** は人手で整理したもので、古典的な場面の網羅を目指すものであり、網羅的ではありません。`build/relations.py` への追加を歓迎します。
- コーパスは中国古典文学サイトの『水滸伝』電子テキストに由来し、少数の OCR 誤字を含みます（抜粋の段階で回避・洗浄済み）。『水滸伝』はパブリックドメインであり、本ツールは閲覧と学習のみを目的とします。
- 本リポジトリのスクリプトおよびデータには、個人情報・鍵・トークン・環境固有の絶対パスは一切含まれていません。
