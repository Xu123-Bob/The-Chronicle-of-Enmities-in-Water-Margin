一个用于 **大众娱乐与阅读** 的《水浒传》人物关系可视化工具。

打开 `index.html` 即可使用 —— 纯静态、零依赖、可离线，双击运行，无需安装任何环境。

### 一、界面：三栏布局

| 栏位 | 内容 |
| --- | --- |
| **左 1/6** | 全书人物名册，按 **天罡三十六 → 地煞七十二 → 宋朝官员 → 普通人（市井草莽）** 四组排列，可按姓名 / 绰号搜索 |
| **中（自适应）** | 力导向关系图谱：**节点＝人物，连线＝关系**；滚轮缩放、拖拽平移、拖动节点、双击居中 |
| **右 1/3** | 点选人物或连线后，展示该关系的 **回目、释义与原著原文摘录** |

**三栏皆可拉伸**：两栏之间各有一条分隔条（鼠标移上去会亮起），按住左右拖动即可调整宽度；
**双击分隔条**恢复默认比例。中栏最小保留 240px，故拉伸有度，图谱不会被挤没。
拖动记录为百分比，窗口缩放时比例自守。

**天罡与地煞**：一百单八将按座次一分为二 —— **天罡三十六**与**地煞七十二**。
左栏名册即按此拆为两组；图谱中 **天罡为金色并外罩金环**，地煞为赭色实心；
左上角除关系图例外，另有一组星阶图例可对照。悬停人物时，提示框会标注「天罡」或「地煞」。

**入场即稳**：图谱在首帧渲染之前，已先在后台把物理模拟预演收敛，并停摆封冻。
因此打开页面时图形 **静止成形**，既无初始乱窜，也无持续微抖；仅在拖拽、筛选等主动操作时才轻微回弹。

右栏的「原文摘录」刻意 **一分为二**，以免混淆：

```
┌─────────────────────────────────────────┐
│ 回目 │ 第十回 朱贵水亭施号箭 林冲雪夜上梁  │  ← 其一：出处
├─────────────────────────────────────────┤
│  原来这人是京师殿帅府太尉高俅……           │  ← 其二：原文
└─────────────────────────────────────────┘
```

### 二、两条核心设计

#### 1. 节点大小 = 出场次数（增幅刻意很小）

半径按 **对数压缩** 计算：

```js
norm = log(1 + 出场次数) / log(1 + 全书最高出场次数)
半径 = 5.5 + 5.0 × norm        // 实际区间约 5.9 ~ 10.5 px
```

因此宋江（4019 次）与一名只出场两三次的小人物相比，半径也只相差不到一倍，
**既有可辨识的层次，又不会喧宾夺主**。

> 统计口径：以全书语料逐名匹配「姓名 + 绰号 + 别称」，并针对潘金莲、阎婆惜等
> 原著中多称「那妇人」「婆惜」的人物，按限定回次补入代称（见 `build/scoped.py`）。

#### 2. 有向关系：行动 → 接受

连线 **带箭头**，方向表示「谁做的，落到谁身上」。共七类，各自成色：

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| **恩** | 施恩与受恩 | 柴进 → 林冲（收留赠银） |
| **义** | 义气、结拜、生死相托 | 鲁智深 → 林冲（野猪林相救） |
| **爱** | 爱慕、婚配、私情 | 西门庆 → 潘金莲 |
| **孝** | 孝亲、人伦、养育 | 武松 → 武大郎（敬兄如父） |
| **仇** | 结仇、怨恨、仇隙 | 高俅 → 林冲（白虎堂陷害） |
| **杀** | 杀伐、害命、血债 | 李逵 → 李鬼 |
| **骗** | 欺瞒、算计、诱赚 | 吴用 → 卢俊义（智赚玉麒麟） |

左上角图例可 **逐类开关过滤**；同一对人物若有往返两条关系，连线会自动分开成上下弓形，
箭头一去一回，不会重叠。

### 三、数据规模

| 项 | 数量 |
| --- | --- |
| 人物节点 | **183**（108 将 + 31 位宋朝官员 / 官差 + 44 位普通人） |
| 关系连线 | **215** 条，七类俱全 |
| 原著摘录 | **215** 段，逐条注明回目 |
| 语料 | 全书 121 篇（楔子 + 120 回），约 88.5 万字 —— **不随仓库提供，见第五节** |

数据文件很小（合计约 113 KB），首屏加载几乎无感。

### 四、目录结构

**最小运行集（7 个文件，约 160 KB）** —— 克隆后只需这些，双击 `index.html` 即可使用：

```
# ── 必需：运行所需 ────────────────────────
index.html            页面骨架（三栏）
css/style.css         样式（宣纸墨色，中国风）
js/graph.js           力导向引擎：自研物理模拟 + Canvas 渲染 + 交互（零依赖）
js/app.js             应用层：名册、图例、详情联动
data/characters.js    人物数据（自动生成）
data/relations.js     关系数据 + 原文摘录（自动生成）
data/chapters.js      回目索引（自动生成）

# ── 随仓库附带 ─────────────────────────
README.md             说明（中文）
README.en.md          说明（English）
README.ja.md          说明（日本語）
LICENSE               MIT 许可证
.gitignore            忽略规则（会话记录、语料、缓存）

# ── 可选：数据生产管线（Python，用于重跑或扩充）──
build/                数据生产管线（Python，可选）
  roster.py           人物名册源数据（108 将座次 / 星号 / 绰号 + 官员 + 普通人）
  relations.py        215 条关系源数据（行动者 / 接受者 / 类型 / 回次 / 释义）
  scoped.py           限定回次的代称规则
  count.py            统计出场次数 → stats.json
  chapters.py         提取回目索引 → chapters.json
  validate.py         校验：人名可解析、双方确实同现于该回
  emit.py             抽取原文摘录 → 生成 data/*.js
  checkjs.py          数据完整性 + JS 括号配平体检

corpus/               《水浒传》语料与抓取 / 抽取脚本
  download.py         抓取公开站点全文 → corpus/raw/
  extract.py          清洗整理 → corpus/txt/
  txt/                正文 121 篇（体积较大，已被 .gitignore 忽略）
```

故 **最简上传即 7 个运行文件 + 3 份说明 + `LICENSE` + `.gitignore`，共 12 个文件**；`build/` 与 `corpus/` 视需而定。

### 五、复现或扩充数据

仓库 **不含原著正文**（`corpus/txt/` 已在 `.gitignore` 中）。若要重跑数据管线，先自行获取语料：

```bash
python corpus/download.py  # 0. 抓取《水浒传》全文 → corpus/raw/
python corpus/extract.py   #    清洗整理 → corpus/txt/
python build/count.py      # 1. 统计出场次数
python build/chapters.py   # 2. 提取回目
python build/validate.py   # 3. 校验关系与回次（应为 issues: 0）
python build/emit.py       # 4. 抽取原文并生成 data/*.js
python build/checkjs.py    # 5. 体检（应为 errors=0）
```

**要加人物**：在 `build/roster.py` 增一行；
**要加关系**：在 `build/relations.py` 增一条 `(行动者, 接受者, 类型, 回次, 释义)`，
回次即语料编号（`0`＝楔子，`1`＝第一回 … `120`＝第一百二十回）。
跑一遍上述脚本即可，原文摘录会 **自动从该回中定位** 同时出现二人的段落，并用释义中的实词加权校准。

### 六、原文摘录是怎么来的

并非人工抄录，而是程序从原著中「找」出来的：

1. 把目标回次切成句；
2. 找出 **同时出现行动者与接受者** 的最小句窗；
3. 按关系类型关键词（杀→「杀 / 死 / 毒 / 血」、骗→「骗 / 赚 / 瞒 / 诱」…）与释义实词加权打分；
4. 剔除含 OCR 噪声的句窗，取最优解。

因此每条摘录都是 **原书原文**，只是未必恰好是该情节最著名的那一句。

### 七、说明与限制

- **回目编号**：以所据电子本为准（其楔子「张天师祈禳瘟疫 洪太尉误走妖魔」单独成篇，
  故正文回次与部分通行本相差一回）。摘录文字与所标回目完全对应，可直接按回目名检索原文。
- **关系条目** 由人工梳理，追求覆盖经典情节而非穷尽；欢迎在 `build/relations.py` 中继续扩充。
- 语料源自中国古典文学网《水浒传》电子本，含少量 OCR 讹字（已在摘录环节做规避与清洗）。
  《水浒传》为公有领域作品，本工具仅作阅读与学习之用。
- 仓库内所有脚本与数据均不含任何个人身份信息、密钥、令牌或本机绝对路径。
